# sandbox-git

สนามซ้อมเรียน Git & GitHub สำหรับทีม

## โปรเจกต์จำลอง: เว็บเมนูร้านอาหาร

ทีมงาน 2 คน ทำงานบนเว็บไซต์เดียวกันด้วยกัน:

- **น้อง A** รับผิดชอบ: หน้าแรก / Header (ส่วนบนของ `index.html`)
- **น้อง B** รับผิดชอบ: หน้าเมนู / Menu (ส่วนล่างของ `index.html`)

## ภารกิจ

| บท | ภารกิจ | เรียนรู้อะไร |
|-----|--------|--------------|
| 1 | Clone + แก้ไฟล์ + Commit + Push | พื้นฐาน Git |
| 2 | ดึงงานของเพื่อน (Fetch / Pull) | sync กับทีม |
| 3 | แยก Branch ทำงานของตัวเอง | ทำงานพร้อมกันไม่ชน |
| 4 | เปิด Pull Request + Merge | ทำงานเป็นทีมผ่าน GitHub |
| 5 | จำลอง Merge Conflict | เอาตัวรอดเมื่องานชนกัน |

## ไฟล์ในโปรเจกต์

- `index.html` — หน้าเว็บร้านอาหาร (ไฟล์หลักที่ใช้ฝึก)
- `test.md` — ไฟล์ทดสอบ
